Database Normalization Process

1NF (First Normal Form)

Atomic columns without repeating groups. Each record contains unique scalar values.

2NF (Second Normal Form)

Elimination of partial dependencies. Non-key attributes fully depend on candidate keys.

3NF (Third Normal Form)

Elimination of transitive dependencies. Non-key columns depend only on primary keys.

BCNF (Boyce-Codd)

Strict determinant rule enforced across multi-attribute candidate keys for audit stability.
