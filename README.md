# 🛡️ Fake Detection Management System (FDMS.AI)

> **Next-Generation Social Media Engagement Integrity Platform**  
> Full-Stack Architecture powered by **Node.js, Express, and PostgreSQL** with **Multi-Role Authentication Portals** and AI-driven Bot Telemetry.

---

## 🌟 Key Upgrades Overview

1. **Full-Stack Node.js + Express Backend**
   - RESTful API layer in `server/` with routes for authentication, user governance, creator management, video analytics, audit reports, neural bot detection, and PostgreSQL introspection.
   - Live health checks, JWT token signing, and system audit logging.

2. **Persistent PostgreSQL Database (`fdms_db`)**
   - All platform information is directly stored in and queried from local **PostgreSQL 18** on port `5432`.
   - Automatic database table creation and schema synchronization on startup via `server/db/schema.sql` and `server/db/seed.js`.
   - Real database tables: `users`, `creators`, `videos`, `reports`, `detections`, and `system_logs`.

3. **Three Distinct Cybersecurity Login Portals**
   - **🛡️ Security Analyst Portal**: For threat investigators & bot telemetry engineers. Default access to forensic detection, click-farm clustering, and anomaly scores.
   - **⚡ System Administrator Console**: For database administrators & security policy directors. Unlocks the live registered user directory, database management, and system governance.
   - **🌐 Brand & Creator Client Portal**: For content creators, talent agencies, and brand sponsors. Direct access to creator health audits and video analytics.
   - **Interactive Switcher & 1-Click Demo Fill**: Switch between portals with tabs or direct landing page buttons, complete with 1-click verified demo account autofill.

4. **Enhanced User Registration (Sign Up Page)**
   - Complete registration form capturing full name, email, phone number, organization, and account role (`Analyst`, `Admin`, or `User`).
   - Passwords securely hashed using **`bcrypt`** (10 salt rounds) before insertion into PostgreSQL.
   - Real-time password strength meter and confirm-password match indicator.
   - Unique email constraints enforced by PostgreSQL with duplicate detection.

5. **Live PostgreSQL Database Architecture Viewer**
   - Real-time engine telemetry: database size, PostgreSQL version, and total active tables.
   - Interactive Table Inspector: Click any table (`users`, `creators`, `videos`, `reports`, `detections`, `system_logs`) to query live rows directly from PostgreSQL.
   - Admin Panel Registered Users Table: View, inspect, or remove registered user accounts directly in PostgreSQL.

## 🗄️ PostgreSQL Database Schema

The database `fdms_db` contains the following normalized relational tables:

- **`users`**: User authentication, bcrypt password hashes, roles, badge IDs, organizations, and login timestamps.
- **`creators`**: Social media profiles with follower counts, engagement rates, platform types, and risk categories.
- **`videos`**: Content post telemetry, views, likes, comments, and upload dates linked to creators.
- **`reports`**: Forensic threat reports generated by analysts with calculated anomaly risk scores.
- **`detections`**: AI neural network detection scan records with fake follower, like, and comment counts.
- **`system_logs`**: System security audit trail recording logins, user creations, and risk triggers.

## 🚀 How to Run the Application

### Prerequisites
- Node.js (v18+)
- PostgreSQL (running locally on port 5432)

### 1. Configure PostgreSQL Environment
The database settings are located in `.env`:
```env
PORT=5000
PGHOST=localhost
PGPORT=5432
PGDATABASE=fdms_db
PGUSER=postgres
PGPASSWORD=Manoj@123
JWT_SECRET=fdms_cybersecurity_quantum_secret_key_2026_jwt_token_auth
```

### 2. Start the Full-Stack Server
From the project root:
```bash
npm start
```
The server will:
1. Connect to PostgreSQL on `localhost:5432`.
2. Automatically verify and initialize all tables and seed default records if needed.
3. Serve the API endpoints and the frontend application at:
   👉 **http://localhost:5000**

## 📡 REST API Endpoints

- `GET /api/health` - Check PostgreSQL connectivity & server health
- `POST /api/auth/register` - Register a new user account into PostgreSQL
- `POST /api/auth/login` - Authenticate against PostgreSQL with role verification
- `GET /api/auth/me` - Get current session profile
- `GET /api/users` - Admin user directory from PostgreSQL
- `DELETE /api/users/:id` - Delete user account
- `GET /api/creators` - Retrieve creators list
- `POST /api/creators` - Save new creator
- `GET /api/videos` - Retrieve video analytics
- `GET /api/reports` - Retrieve audit reports
- `POST /api/reports` - Generate and save audit report
- `POST /api/detections/run` - Execute AI fake detection and store in PostgreSQL
- `GET /api/database/overview` - Live PostgreSQL database statistics & table counts
- `GET /api/database/table/:name` - Query up to 50 live rows from any database table
